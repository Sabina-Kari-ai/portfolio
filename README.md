# Sabina Karimova — Portfolio

Portfolio personnel en ligne : **https://sabinakarimova.com**

Étudiante Pré-MSc Pro à EPITECH Nantes, à la recherche d'une alternance IT (contrat d'apprentissage) à partir de janvier 2027.

## Contenu

- **Portfolio** (`index.html`) : présentation, projets, compétences, CV, centres d'intérêt et contact.
- **CV numérique** (`cv.html`) : CV interactif bilingue avec globe 3D.
- **Jeux jouables dans le navigateur** :
  - *Dodge Game* — shoot'em up spatial en 3D (v1 Python/Pygame → v2 JavaScript/Three.js), `dodge.js`
  - *Hangman* — jeu du pendu avec photo pixelisée (v1 Python/Pygame → v2 JavaScript/Canvas), `games.js`

## Technologies

HTML · CSS (Grid, Flexbox) · JavaScript (sans framework) · Three.js / WebGL · Canvas

## Fonctionnalités

- Bilingue français / anglais (textes et textes alternatifs des images)
- Responsive : ordinateur, tablette et mobile
- Accessibilité : attributs `alt` sur toutes les images, `prefers-reduced-motion` respecté
- Terre 3D interactive (à faire tourner à la souris ou au doigt)

## Lancer en local

Ouvrir le dossier avec un petit serveur local, par exemple :

```bash
python -m http.server 8000
```

puis aller sur http://localhost:8000
