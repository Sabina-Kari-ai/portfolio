Progression

Ce que j'ai appris cette année

Mes projets m'ont fait progresser sur des points précis, du premier jeu en Python jusqu'au travail en équipe.

Py

Du Python au web

J'ai d'abord écrit Hangman et Dodge Game en Python avec Pygame, puis je les ai recréés en JavaScript pour qu'ils tournent directement dans le navigateur.

Le front-end sans framework

Ce portfolio et mon CV numérique m'ont appris le HTML sémantique, le CSS (Grid, Flexbox), le JavaScript, Three.js pour la Terre 3D, ainsi que le bilingue, le responsive et l'accessibilité.

DB

Le back-end en équipe

Sur le JobBoard, projet d'équipe EPITECH, j'ai travaillé avec PHP et MariaDB : authentification des utilisateurs, gestion des données et partage du code sur GitHub.

Git

Travailler proprement avec Git

J'ai pris l'habitude de faire un commit par modification, avec un message qui explique ce qui change, pour que l'historique du dépôt reste lisible par l'équipe et par les enseignants.
